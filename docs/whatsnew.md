# What's New?

## Version 1.1

* **New: Prediction page.** Estimate (impute) the values of selected features
  from the observed ones using a non-parametric Bayesian network built on your
  data. The results include a per-sample table, predicted-vs-observed plots
  with diagnostics and CSV export. See
  [Predicting Values](user-guide/prediction.html).
